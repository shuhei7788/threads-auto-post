投稿ダッシュボード

はじめに

このダッシュボードは、GitHub のトークンを使って投稿を編集します。トークンはこのブラウザの中にだけ保存されます。

  1. GitHub のトークン作成画面を開く
  2. Token name に dashboard、Expiration は一番長い期間を選ぶ
  3. Repository access で「Only select repositories」→ threads-auto-post
  4. Permissions の Contents を「Read and write」にする
  5. 「Generate token」を押し、表示された文字列を下に貼る
